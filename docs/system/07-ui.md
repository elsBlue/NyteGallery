# 7. UI

All UI is Jetpack Compose in one activity. The main screen is `GalleryScreen` (`ui/GalleryScreen.kt`). The other
files are `AppLock.kt`, `DeviceImport.kt`, `VaultMenu.kt` and `SettingsAbout.kt`. There is no Navigation component:
pages are boolean or nullable state flags in `GalleryScreen`, drawn as full-screen layers.

## 7.1 Theme and colours

- **Dark is the default.** `light` is a `remember { mutableStateOf(false) }`, so it's **not saved** and every
  launch starts dark. The sun/moon button switches it. The system bar icon colours follow it
  (`WindowInsetsControllerCompat`).
- Background: a solid colour (`#FBF9F6` light / `#12141A` dark), the `bg_light`/`bg_dark` drawable at 50% alpha, and
  a gradient wash on top.

| Name | Value | Use |
|---|---|---|
| Paper | `#F7F3EE` | card paper |
| Ink | `#3A2C32` | text on cards |
| DotA / DotB / DotC | `#FF4D6A` / `#FF8AA0` / `#FFC0CC` | accent pink (buttons, selection, card header dots) |
| AddGreen | `#2F9B68` | "Add Images", restore ticks |
| Panels | `#F7F4EF` / `#12141A` | full-screen pages (light/dark) |
| Fields, chrome buttons | white / `#1C1E26` | inputs, round buttons |
| Grid background | `#F7F4EF` / `#0C0D11` | photo grid |

## 7.2 Window classes (`adaptive`)

| Class | Rule | Effect |
|---|---|---|
| `Landscape` | width > height | stage and grid side by side; Add/Restore move to the side panel when the grid is closed |
| `TallWide` | portrait and width ≥ 600 dp (tablets, unfolded foldables) | card size from width bands (`cardFit`); grid `Adaptive(88.dp)` |
| `Phone` | anything else | grid `Fixed(4)`; card width 0.62 × width, or 0.42 on a compact phone |

`wideCap` limits the width of the menu, settings, about, backup and lock pages to **520 dp** on wide screens.

## 7.3 Main screen layout

```
┌──────────────────────────────────────────────┐
│ [lock]                         [sun] [menu]  │  ← only [sun] while locked
│               NYTE GALLERY                   │
│        name of photo · 3 November 2026       │  ← ActiveLabel (pencil when grid open)
│                                              │
│          ◄  card  [ CARD ]  card  ►          │  ← 3-D carousel (stage)
│                                              │
│              [delete] [✎]                    │  ← ActionRow
│ ─────────────── grid (optional) ──────────── │  ← PhotoGrid 40% height in portrait
│ [Restore]       [ Add Images ]   [🗑] [▦]   │
└──────────────────────────────────────────────┘
```

- **Portrait** with the grid open: stage weight 0.6, grid weight 0.4. Grid closed: the stage fills the screen.
- **Landscape** with the grid open: a Row split 0.5 / 0.5. Grid closed: the side info and actions take
  `1 − 0.58` of the width.
- **Trash open:** `TrashGrid` replaces the stage.
- Chrome buttons:
  - lock (top start);
  - sun/moon and menu (top end);
  - Trash (bottom end, only when Trash isn't empty);
  - grid toggle (bottom end, only when there are photos);
  - "Restore" pill (bottom start);
  - green "**Add Images**" (bottom centre, or centred alone when the vault is empty).

## 7.4 Carousel

`BoxWithConstraintsFill` draws only **3 cards**: the active card and its two neighbours.

- Position: drag offset into a relative angle with **58° per step**. Cards sit on a circle with radius 0.52 × width
  (0.34 on compact phones). `TallWide` and `Landscape` use band-based sizes (`cardFit`).
- Transform per card:
  - scale from 0.62 to 1.12, with an extra ×1.04 for the active card;
  - alpha `(1.15 − |rel|/130)` clamped to 0.15..1;
  - `rotationY = −rel × 0.72` (±62° max);
  - `rotationZ = rel × 0.045`;
  - `cameraDistance` 16 dp.
- Swipe left or right to turn the carousel. The grid tiles can also pick the active photo.
- Card: paper frame with a header strip of 34 dp (three dots, the name clipped to 16 characters, the year), and the
  photo with height about 1.32 × width.
- While a photo is decoding, the card shows a `LoadingShimmer`, which fades in only after a short delay so fast loads don't flash. The **lens button** on the active card opens
  **FullView**.
- `PhotoImage` decodes on `Dispatchers.IO.limitedParallelism(2)`, with a longest edge of 1080 px by default. Results
  go into the in-memory cache `ThumbMemory` (see [Storage](03-storage-encryption.md)).

## 7.5 Grids

- **PhotoGrid**:
  - The first tile is "+" (import).
  - The active photo has a pink tint (`#33FF4D6A`).
  - Tapping a tile makes it active in the carousel.
- **TrashGrid**:
  - Header: "Trash · deleted automatically after 30 days" plus "**Empty**".
  - Each tile has a restore button.
  - A pill "N images restored" shows for 2 s, and the count adds up while restoring quickly.
- **RestorePage** (export) and **DeviceImportPage** (import) use the same column rules.

## 7.6 Overlays and dialogs

| Overlay | Trigger | Content |
|---|---|---|
| `TransferDialog` | Any import, export, backup or restore | Non-dismissable, `#1C1E26`. Label plus "X of Y · P%", or "This can take a while" |
| `NoticeOverlay` "MOVE TO TRASH" | First time a photo is deleted | Explains Trash and the 30 days |
| `EmptyTrashOverlay` | "Empty" in Trash | The user must type `delete` to confirm the permanent delete |
| `RenameOverlay` "RENAME" | Pencil | Text field, Close / Save. The name is trimmed, an empty name is ignored, and there's **no length limit** |
| `FullView` | Lens button | Black background; pinch zoom 1–6× with pan limited to the image; title "Nyte Gallery"; close ✕ |
| `RemoveOriginalsOverlay` | After an import | See [Import §5.4](05-import-export.md#54-remove-or-keep-originals-removeoriginalsoverlay) |
| `LockConfirm` | Lock button | "LOCK APP", see [App lock](04-app-lock.md) |
| Menu sidebar | Menu button | 292 dp panel from the right with rows Backup / Restore backup / Settings / About |

## 7.7 Settings and About

**Settings**:
- **General:**
  - "Recycle bin" opens Trash, or shows the toast "Trash is empty".
  - "Clear cache" opens the confirm dialog "CLEAR CACHE", which deletes `cacheDir` and `externalCacheDir`, then
    shows the toast "Cleared X".
- **Security:** Change lock / App lock, Recovery code.
- **Backup:**
  - "Last backup: …";
  - Back up;
  - Restore backup;
  - Check a backup file.

**About**:
- App icon, "Nyte Gallery", "Version 1.0" (`BuildConfig.VERSION_NAME`), "by Nytefall Interactive".
- **Send feedback:** `mailto:nytefall.interactive@gmail.com` with the subject "Nyte Gallery feedback (version X)".
  If no email app is found, a toast shows the address.
- **Privacy policy** and **Terms of service** open the GitHub pages for `docs/policy/PRIVACY_POLICY.md` and
  `docs/policy/TERMS.md` in a browser.

## 7.8 Back button order

`BackHandler` checks the following in order, and the first match wins:

1. A transfer is running, a recovery code is showing, or a recovery reset is in progress: **blocked**.
2. Lock setup is open: close it. The lock confirm is open: close it.
3. Locked: **blocked**.
4. The remove-originals sheet is open: act as **Keep originals**.
5. Then close, in order: change-lock / recovery-code settings, backup (unless busy), restore backup, about, settings,
   menu, device picker, full view, rename, trash notice, empty-trash dialog, restore page, Trash, grid.
6. Otherwise "Press back again to exit"; a second Back within 2 s exits.

## 7.9 Other behaviour

- When the vault becomes empty, the grid and the Restore page close.
- On Android 13+, the notification permission (`POST_NOTIFICATIONS`) is requested once, at the first transfer, for
  the progress notification. Denying it doesn't block the transfer.
- `FLAG_SECURE` covers the whole UI (see [App lock §4.9](04-app-lock.md#49-flag_secure-screenshots-and-recents)).
- All UI text is English and hard-coded in Kotlin. `strings.xml` holds only `app_name`. There's no localisation.
